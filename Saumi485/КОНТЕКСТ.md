## Зафиксированные решения (2026-09-04)

### 1. mmp32.exe — не патчить байты, даты из архива

| Поле | Значение |
|------|----------|
| sha256 (начало) | `0a39282c…` |
| size | `35627696` |
| mtime архива (epoch) | `1624875940` = 2021-06-28 |

После `tar` на Linux **birth (Создан) = «сейчас»** — это **не норма**.  
SAUMI смотрит size + **создание (birth)**; чужой birth → локальное автообновление → диалог «Saumi.exe занят».

**Как решили:** после распаковки установщик **обязан** выставить:
- **Изменён (mtime)** = mtime из tar;
- **Создан (birth/crtime)** = тот же epoch `1624875940`.

Способ: sibling-копия + `debugfs` `set_inode_field … crtime @epoch` + `mv` (формат **`@epoch`**, не `YYYYMMDD…`; флаг `-f` у debugfs = файл команд, не «force»).  
Нужны **ext4/ext3** + `debugfs` (e2fsprogs). Если birth ≠ цели — установщик **падает** (hard-fail).

**Важно:** после **запуска** SAUMI сам может снова сдвинуть mtime/birth при попытке обновления; sha при этом часто остаётся `0a39282c…`. Верный birth на установке снижает ложные обновления; полного «выключить обновление» без поломки входа не нашли.

### 2. Флаг запуска: только `/oldupdate`

Команда: `wine mmp32.exe /oldupdate`.

| Флаг | Вердикт |
|------|---------|
| `/oldupdate` | **рабочий** (оставляем) |
| `/updated` (AdminGuide §3.1.1) | **не использовать** — на komp-05: «обновление не произведено, обратитесь к администратору» |

### 3. Окна: сразу режим 2, гибрид отменён

| Режим | X11 | Когда |
|-------|-----|--------|
| **2 (по умолчанию)** | `Managed=Y`, `UseTakeFocus=Y`, `Decorated=Y` + `saumi_taskbar_fix.sh` | рабочий на komp-05 |
| **1 (запасной)** | `Managed=N` + hide + minimize-guard | `sudo bash instalSaumi.sh --wm-mode=1` |

**Гибрид mode1→mode2 mid-session — не работает:** Wine читает `Managed` при **создании** окна; смена реестра после старта не переводит уже созданные окна.  
**Не входит:** гибрид окон. Режим 2 задаётся до wine; `saumi_wm_boot_switch` удалён.

Класс окон для taskbar: **`saumi.exe`** (не только `mmp32.exe`).

`Managed=Y` выставляется **до** старта wine (в `startSAUMI.sh` / postinstall).

### 4. Excel

Остаётся **Xlsx.23** (`files/src/excel_proxy/SaumiExcelProxy.dll`, даты без 00:00:00). Не откатывать без запроса. В golden tar попадёт при следующем `bake_into_tar.sh`.

### 5. Только полная установка + golden tar

Актуальный `instalSaumi.sh` + `install/SAUMI1860wine.tar.gz`. Отдельные hotfix-патчи не храним.

## Как собирать (пересборка с нуля)

Общий принцип: **offline-first**, два этапа (Astra → Mac). Детали также в `../КОНТЕКСТ.md`.

### A. Базовый prefix на Astra

```bash
# Mac → Astra: исходники
cd Saumi485/files/scripts
bash deploy_to_astra.sh build-src

# На Astra
~/saumi_build_src/rebuild_saumi_on_astra.sh
```

`build_saumi1860_prefix.sh`:
```
wineboot → winetricks (comctl32 msxml3 msxml6 riched20 corefonts)
→ .NET 3.5 offline → unzip SAUMI485.zip → Oracle + tnsnames
→ startSAUMI.sh (mmp32 /oldupdate) → ~/SAUMI1860wine.tar.gz
```
Базовый tar **без** wine-11.0 и **без** Excel/EW/Guardant bake.

Скопировать `~/SAUMI1860wine.tar.gz` на Mac → `Saumi485/install/`.

### B. Mac: wine-11.0 + патчи + Guardant + sync установщика

```bash
cd Saumi485/files/scripts
bash inject_wine_into_tar.sh
bash bake_into_tar.sh          # helpers; Excel/EW уже в tar, не из patches/
bash bake_licence_into_tar.sh
bash sync_release.sh           # обновляет только instalSaumi.sh в install/
```

Bake **не** меняет байты mmp32 и **не** подменяет Excel/EW извне (канон — уже в golden). Даты birth на клиенте выставляет **установщик** после `tar xf`.

### C. Выкладка на сервер установки

```bash
bash deploy_to_astra.sh saumi
# на сервере: содержимое → /var/install/saumi485
sudo bash instalSaumi.sh
```

Проверка после установки:

```bash
stat -c 'size=%s mtime=%Y birth=%W' ~/Saumi/drive_c/SAUMI/mmp32.exe
# ожидание: size=35627696 mtime=1624875940 birth=1624875940
sha256sum ~/Saumi/drive_c/SAUMI/mmp32.exe   # начинается с 0a39282c
```

Обновить только скрипты старта без полной переустановки:

```bash
sudo bash instalSaumi.sh --refresh-start
```
