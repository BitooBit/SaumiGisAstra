# Saumi4113 — контекст

**Направление:** клиент SAUMI **4.11.3** + Guardant Net под Astra Linux SE 1.8.6 (Wine 11.0).  
**База:** Wine-prefix / установщик из `../Saumi485/` — заменена только папка `drive_c/SAUMI` на `SAUMI4113.zip`.  
**Не входит:** SasCore → `../SasCore6761/`.

---

## install/ — на сервер `/var/install/saumi4113`

| Файл | Назначение |
|------|------------|
| `instalSaumi.sh` | Установщик «один клик» (`INSTALLER_REV=2026-09-10-prod4-v28-saumi4113`) |
| `SAUMI1860wine.tar.gz` | Wine-prefix (485 golden + клиент 4113) |
| `ИНСТРУКЦИЯ.docx` | Пути **`/var/install/saumi4113`**, версия **4.11.3** (обновлена 2026-09-10) |

**Команда:**

```bash
cd /var/install/saumi4113
sudo bash instalSaumi.sh
```

Prefix пользователя: `~/Saumi`.

**Размер tar ~1.6 ГБ vs ~2.0 ГБ у 485:** ужат только `drive_c/SAUMI` (нет `map-*.rar` ~524 МБ и лишних dll из 485); runtime/oracle без изменений.

## Зафиксированные решения (наследуются от 485)

- Запуск: `wine mmp32.exe /oldupdate`
- Окна: режим **2** (`Managed=Y` + taskbar_fix)
- mmp32: байты не патчить; birth/mtime выставляет установщик (`debugfs` + ext4)
- Excel: Xlsx.22 proxy
- Поставка: 2 файла (`instalSaumi.sh` + tar)
