# SasCore6761 — контекст

**Направление:** SasCoreService (ГИС ГМП).  
**Не входит:** клиент mmp32 → `../Saumi485/`.

**Поставка — два файла:** `installSasCore.sh` + `SasCoreWine.tar.gz` (плюс `ИНСТРУКЦИЯ.docx`).  
Второй папки со скриптами/dll нет: .NET 4, GAC, CRT, NDP и `bin/*.sh` внутри tar.

## Параметры Oracle

`install_sascore.sh` спрашивает TNS/логин/пароль **только если** нет рабочего plaintext `Settings.xml`.  
Перед сносом prefix копирует Settings.xml и возвращает после tar.

```bash
sudo bash installSasCore.sh

SASCORE_TNS=MMPSRV SASCORE_USER=SM SASCORE_PASSWORD=… \
  sudo bash installSasCore.sh
```

## Установка

| Prefix | Что делает |
|--------|------------|
| нет папки | tar → порты от root → Oracle (если нет Settings) → старт |
| есть, **целый** (exe+sha, Framework, GAC System.dll, NDP v4, CRT, wine-11) | tar не трогает; порты, старт; Settings не ломает |
| есть, **битый** | стоп → бэкап Settings → снос → tar → вернуть Settings |
| `--reinstall` | всегда снос + tar (Settings бэкапит) |

**Порты:** `8080 8732 8733 9000 80 443`. Открывает `installSasCore.sh` от root.

Probe без LISTEN (нет живой БД) — **не FAIL установки**, если процесс жив.
